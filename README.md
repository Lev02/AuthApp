# MyApp

## Описание

**MyApp** — это WPF-приложение, построенное с использованием паттерна **MVVM**. Приложение поддерживает взаимодействие с внешним API для регистрации, авторизации и управления пользователями через шину сообщений (**Messenger**) из **CommunityToolkit.MVVM**. Основные функциональности включают:

- Регистрация пользователя
- Авторизация
- Разлогин
- Отображение данных пользователя
- Уведомление нескольких ViewModel о состоянии авторизации

## Структура проекта

Проект разделён на несколько слоёв для обеспечения чистой архитектуры и удобства расширения:

### 1. **Presentation**
Слой, отвечающий за пользовательский интерфейс (UI). Включает:
- **Views**: XAML-страницы, отвечающие за представление интерфейса.
- **ViewModels**: Связывают представление с бизнес-логикой и управляют состоянием UI.

### 2. **BLL (Business Logic Layer)**
Слой бизнес-логики, который включает:
- **ViewModels**: Логика управления данными, используемыми в UI.
- **Services**: Логика взаимодействия с внешним API.
- **Messages**: Система уведомлений через **Messenger** для обмена сообщениями между ViewModel.

### 3. **DAL (Data Access Layer)**
Слой, который отвечает за взаимодействие с внешними данными (например, с API).
- **UserService**: Сервис для взаимодействия с внешним API, включает методы для регистрации, авторизации, получения данных пользователя и разлогина.

### 4. **Core**
Общий слой, включающий модели и интерфейсы.
- **Models**: Модели данных, такие как `User`.
- **Interfaces**: Интерфейсы, такие как `IUserService`, для обеспечения зависимости от абстракций, а не от реализаций.
- **Messages**: Классы для сообщений, используемых в шине сообщений.
